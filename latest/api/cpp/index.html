C++ API

The public headers are under ernie/scene, ernie/session, ernie/app, ernie/geometry, ernie/util and ernie/device, installed with Ernie and found with find_package(Ernie). The classes most programs start from:

Area Classes
Scene Scene, Prim, Path, Value, Tensor, EditHistory
Typed prims (guide) SchemaView, PrimTypeDef, AttributeDef, SphereLight, Camera, RenderSettings
Rendering Renderer, RendererOptions, RenderProductOutput, ProductFrame
Cameras and lights CameraParams, LensModel, CameraView, LightParams, FrameParams
Extending BrdfRegistry, SensorFilterRegistry, Overlay, RenderDelegate
Viewer Viewer, Panel, WidgetPanel
Devices VulkanContext, ComputeInterop

Every class is under Classes, by header under Files, and the free functions under Functions.
