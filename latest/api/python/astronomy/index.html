Astronomy

Time, sky coordinates and stars.

julian_date 

julian_date(year: int, month: int, day: int, hours: float = 0.0) -> float

The Julian date of hours UT past midnight of a Gregorian date (Meeus, chapter 7).

greenwich_sidereal_time 

greenwich_sidereal_time(julian_date: float) -> float

Greenwich mean sidereal time in degrees at a Julian date (Meeus, equation 12.4).

celestial_to_local 

celestial_to_local(latitude: float, longitude: float, julian_date: float) -> object

A StarField's transform for the sky over a site (degrees, east positive) at a Julian date: J2000 equatorial to x east, y north, z up.

star_illuminance 

star_illuminance(magnitude: float, zero_point: float = 2.54e-06) -> float

Lux of a star of visual magnitude magnitude (2.54e-6 lux at magnitude 0).

color_index_to_temperature 

color_index_to_temperature(color_index: float) -> float

A star's temperature in kelvin from its B-V colour index (Ballesteros 2012).

synthetic_stars 

synthetic_stars(count: int, seed: int = 1, faintest: float = 6.5) -> dict

count made-up stars as lists of right_ascension and declination (degrees), magnitude and color_index, the same for the same seed.
