AsyncDownload 

AsyncDownload(url, path)

define_planet_surface 

define_planet_surface(scene, path, radius, albedo, material)

A smooth planet of radius metres at path: a planet Terrain of flat cube faces, its surface at the world's z = 0 (its centre radius below the origin), drawn with a Material of normal albedo albedo (linear RGB) at material. The ground under an atmosphere, which is the air alone (as the C++ demos' DefinePlanetSurface).

download 

download(url, path, report=print, progress=None)

Downloads url to path, its directory made as needed: streamed into path + ".part", renamed when complete. A part left by a download stopped or failed before is resumed (an HTTP range request; from the start if the server ignores it), and failed attempts resume up to five times, going to report. progress, when given, is kept up to date: its bytes in hand, its total (0 until the server says), and its cancelled, which stops the download (DownloadCancelled).

fetch_ranges 

fetch_ranges(url, ranges)

The bytes of ranges [(first, last), ...] of url, each inclusive, in one request (HTTP range requests; several come back as multipart/byteranges, RFC 9110 section 14.6).

run(demo, args)

Steps and renders demo until its window closes or it has run --num-frames, then writes --output, runs its final test and reports the benchmark. In a window the Demos panel lists the demo files beside this one. Returns the demo running at the end.
