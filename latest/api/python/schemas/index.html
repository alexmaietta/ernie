load_scene 

load_scene(
    description: dict[str, Any] | str | PathLike[str], scene: Scene | None = None
) -> Scene

Builds prims from a description, into scene or a new Scene, and returns the scene.

The description is a dict (or JSON text, or the path of a .json file) from prim paths to prims; each prim is a dict whose "type" names its type (none for an untyped prim, or to leave an existing prim's type alone), whose dict values are its children by name, and whose other values are its attributes, by Python name (radius) or USD name ("inputs:radius"), with translate, rotate, rotation_order, orient and scale setting its transform ops (orient a Quat or [w, x, y, z]) and transform a 4 x 4 matrix (rows of four); C++ reads the same format (ernie/scene/scene_json.h)::

ernie.load_scene({
    "/World": {"type": "Xform",
        "Rock": {"type": "Sphere", "radius": 0.5,
            "translate": [0, 0, 1]},
        "Sun": {"type": "DistantLight", "angle": 0.53}},
    "/Render/Settings": {"type": "RenderSettings",
        "resolution": [640, 480]},
})

C++ loads it (LoadScene), so both read a description the same way: each value is read as its attribute's declared kind, checked as setting it is. Lists for array attributes become arrays: int32 for those of whole numbers (face_vertex_indices, proto_indices; AttributeDef.is_integer), float32 for the rest (points, heights), whatever the numbers look like; nested lists for one that takes an array in place of its value (AttributeDef.takes_array: per-vertex display_color) are a float32 array. A dict may hold Quats, Paths and prims too, and arrays (NumPy, or any DLPack array, a CUDA one included): where an array goes, written as it is, shared and not copied, its dtype kept, as Scene.write writes one; elsewhere (translate, a radius) read as the numbers it holds, which needs a CPU array.

Raises:
  • ValueError –

    A value its attribute does not take, or JSON that does not parse, naming the prim and key (or the line and column).

  • TypeError –

    The description is not a dict, JSON text or a file path.
