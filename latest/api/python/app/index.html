Viewer

The interactive viewer and its panels, themes and callbacks (ernie.app).

Ernie's interactive viewer: a window onto a Scene, driven by run() or step().

DemoRunner 

DemoRunner(options: DemoOptions, title: str = 'Ernie demos')

Runs demos as Newton's examples run: in a window, headless or without a viewer, writing --output, running --test checks and reporting --benchmark; in a window a Demos panel switches between the catalogue's demos.

Opens the viewer the options ask for (none for --viewer null or --benchmark); demos built from now on register in a scope of their own.

Methods:

Name Description
create

Builds the catalogue's demo index for this runner.
request_reset

Builds the running demo afresh before the next frame, as the panel's Reset does.
request_switch

Switches to the catalogue's demo index before the next frame, as the Demos panel's menu does. With a viewer only.
run

Runs demo until its window closes or it has run its frames, then writes --output, runs test_final and reports the benchmark; returns the demo running at the end (the Demos panel may have switched), or None. Closes the viewer.
set_catalog

The demos the Demos panel lists, and which of them runs first.

Viewer 

Viewer(
    scene: Scene,
    title: str = "Ernie",
    width: int = 1600,
    height: int = 900,
    hidden: bool = False,
    validation: bool = False,
    device: str = "",
    theme: Theme | None = None,
    layout: str | PathLike | None = None,
    settings: Path = ...,
    renderer: str = "raster",
    vsync: bool = False,
)

A window onto a Scene: a docked viewport plus panels. Edits from code and from the GUI go through the same scene. Drive it with run(), or call step() from your own loop.

Opens the window (none when hidden) on a Vulkan device. Raises RuntimeError without a window system or Vulkan device.

Methods:

Name Description
add_hud_item

Adds a line "label: value(viewer)" to the viewport's heads-up display, refreshed a few times a second; value returns a str. Returns an id.
add_menu_item

Adds label to the menu bar's menu; calls action(viewer).
add_panel

Adds a WidgetPanel titled title, docked at dock in the default layout.
add_viewport_menu_item

Adds label to the viewport's settings menu; calls action(viewer), and shows a check while checked(viewer) returns True. Returns an id.
add_viewport_toggle

Adds a toggle to the viewport's eye menu, such as for physics contacts or labels. With overlay, it shows and hides that scene overlay in the viewport; changed(viewer, shown) is told when the user switches it. Returns an id.
camera_from_view

Defines a Camera prim at path with the active camera's pose and lens.
capture

Writes the next viewport frame to path as PNG.

new_scope

A registration scope not used before (see scope), without making it current.
on_frame

Calls callback(viewer, frame_info) at the start of every frame, before the UI; returns an id for remove_callback.

Calls callback(viewer, frame_info) after the frame is submitted and presented; its edits show in the next frame. Returns an id.

Calls callback(viewer, frame_info) after the UI, just before the scene is synced and rendered, so its edits show in this frame; returns an id.
on_selection

open_scene

Replaces the stage with the scene a JSON file describes (the format of ernie.load_scene and ernie.save_scene), as File > Open Scene does: removes every prim but the viewer's own and every overlay but its own, loads the file and starts the session over (clear_scene, then reset_session). A file that does not load raises ValueError and leaves the stage as it was.
panel_visible

Whether the panel titled title (such as "Profiler") shows.
pick

The prim the viewport shows at pixel (x, y) of its last frame; an empty Path for the background.
redo

Redoes the last undone GUI edit.
remove_callback
remove_panel

remove_viewport_item

Removes a viewport toggle, heads-up display item or viewport menu item.
rename

Renames a prim, moving its descendants, as one undo step; returns its new path.
reset_session

Starts over on the scene's present content once it has been replaced, as open_scene and the demo runner do: clears the selection and undo history, and picks the RenderSettings, the camera (perspective_camera, framing the scene) and the lighting as on opening, except those set (settings, active_camera, lighting) since clear_scene or opening.

undo
