Quat 

Quat(w: float, x: float, y: float, z: float)

A rotation as a quaternion, Quat(w, x, y, z) with the real part first as USD writes one (xformOp:orient). Arrays of quaternions (PointInstancer orientations, xformOp:orient rows) are x, y, z, w instead, as in USD's memory; Quat.from_xyzw reads that order, as SciPy, ROS and Warp use.
