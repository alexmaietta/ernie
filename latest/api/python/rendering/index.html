Rendering

Rendering scenes and render products, and reading their outputs on the host or the GPU.

Renderer 

Renderer(backend: str = 'raster', validation: bool = False, device: str = '')

Renders a Scene's terrain, meshes, materials, lights, cameras and render settings on a GPU, with one of Ernie's render backends.

Opens a GPU, preferring one whose name contains device, with the Vulkan validation layer when validation is set and it is installed, and the render backend (see backends) on it. Raises RuntimeError without a Vulkan device and ValueError for an unknown backend.

Methods:

Name Description
add_light_pattern

Registers a laser pattern written in Slang, for LaserLights to name in ernie:laser:pattern: struct type_name in module slang (which may import light_pattern;) implementing ILightPattern, whose float emission(LightPatternInput input, LightPatternParams p) gives the relative power per unit area of the tangent plane at input.t = (x / z, y / z), averaged over input.footprint of it (input.beam being the beam's own radius there, for beamlet); any scale, as Ernie integrates it over |t| < extent so the laser emits its power, unless normalized says it integrates to 1. params is {name: default} in order, or a list of {"name", "default", "description"}; LaserLights set them in ernie:laser:pattern:params, read with p.get(i), and their ernie:laser:pattern:data and ernie:laser:pattern:image are p.data(i) and p.image(uv, footprint). Raises ValueError for an invalid pattern or one that fails to compile, with the compiler's diagnostics.
add_sensor_filter

Registers a sensor filter written in Slang, for SensorFilter prims to name in ernie:filter:type: struct type_name in module slang implementing IBandFilter (kind="band", on the spectrum), IPixelFilter (kind="pixel", domain "electrons", "digital", "rgb" or "display"), or for kind="spatial", which reads the pixels around its own through a SpatialImage, ISpatialBandFilter (domain "spectrum") or ISpatialPixelFilter (the others), with a nested Params struct of one float per parameter. params is {name: default} in order, or a list of {"name", "default", "description"}; prims set them as inputs:. Raises ValueError for an invalid filter or one that fails to compile, with the compiler's diagnostics.
