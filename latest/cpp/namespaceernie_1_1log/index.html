Namespace ernie::log

Namespace List > ernie > log

What Ernie prints about itself on standard output, as Warp does ( wp.config.quiet ,wp.config.verbose ): a banner once it starts on a GPU, with its version, device and cache folders, and a line for each shader it compiles, more with verbosity (shaders and textures its caches answer) and nothing when quiet.More...

Detailed Description

The level starts from the environment: ERNIE_QUIET set (to anything but "" or "0") is Quiet, else ERNIE_VERBOSE set is Verbose, else Normal; SetVerbosity (Python's ernie.config.quiet and ernie.config.verbose) changes it, before the banner to silence that too.

Reference: NVIDIA, Warp warp.config (quiet, verbose) and its kernel cache messages.
