Detailed Description

Planes are stored as (a, b, c, d) with a*x + b*y + c*z + d >= 0 inside, and are not normalised, which the sign tests below do not need. Clip space depth is WebGPU's [0, 1].

References: * G. Gribb and K. Hartmann, "Fast Extraction of Viewing Frustum Planes from the World-View-Projection Matrix", 2001. * T. Akenine-Moller, E. Haines, N. Hoffman et al., "Real-Time Rendering", 4th ed., CRC Press, 2018, section 22.10.1 (plane/box test with the box's positive vertex).
