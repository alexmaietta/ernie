Detailed Description

A level-0 node spans leafCells x leafCells grid quads; a level-L node spans leafCells * 2^L and the single root node covers the whole raster. The tree stores only each node's min and max height, so selection can bound nodes in 3D for range and frustum tests.

Select walks the tree from the root and picks, for each region, the coarsest level whose range covers it (Strugar 2009, algorithm 1). Every node is drawn as its four quarters, so all patches share one PatchCells() grid and differ only in origin and vertex spacing.

Within each level's range the vertex shader morphs vertices towards the next coarser level, so switching level never pops; see terrain.slang. With a first range of at least MinFirstRange, neighbouring patches differ by at most one level and their shared edges match exactly, so no skirts or stitching are needed.

References: * F. Strugar, "Continuous Distance-Dependent Level of Detail for Rendering Heightmaps", Journal of Graphics, GPU, and Game Tools 14(4):57-74, 2009. https://doi.org/10.1080/2151237X.2009.10129287 * P. Lindstrom, D. Koller, W. Ribarsky, L. F. Hodges, N. Faust and G. A. Turner, "Real-Time, Continuous Level of Detail Rendering of Height Fields", SIGGRAPH '96, 109-118, 1996. https://doi.org/10.1145/237170.237217

Builds the min/max height pyramid of heights .

ernie::LodQuadtree::LodQuadtree (
    const RasterView & heights,
    std::uint32_t leafCells
)

Cells that are not finite or equal the nodata value are ignored, and nodes without valid cells are never selected. The tree keeps no reference to heights.

Parameters:

  • leafCells Grid quads along a level-0 node; a power of two of at least 4.

Exception:

  • std::invalid_argument if leafCells is invalid, the raster is smaller than 2 x 2, or the tree would need more than kMaxLevels levels.

function MinFirstRange

Smallest first range for which selection keeps neighbours within one level of each other and every shared edge is fully morphed on the finer side and unmorphed on the coarser side. 

float ernie::LodQuadtree::MinFirstRange (
    float exaggeration,
    float morphStart
) const

For each level L below the root this needs the 3D diagonal of every level-L node to be at most morphStart * range[L]: any vertex on an edge between levels L and L+1 then lies between range[L] (finer side fully morphed) and the coarser level's morph start.

Parameters:

  • morphStart Fraction of each level's distance band before morphing starts, in (0, 1).
