Detailed Description

  • settings: the given RenderSettings prim, or the first one outside tokens::kSessionRoot when the given path is empty; empty if there is none, which leaves every option at its default.
  • camera: the settings' camera relationship, or else the first Camera outside the session root.
  • terrain: the first visible Terrain.
  • material: the terrain's material:binding when it names a Material.
  • the lights, from the settings' ernie:lights relationship when it is set (its visible light prims), or else from every visible light outside the session root: light is the first DistantLight by path, the sun, with cascaded shadows; lights every other DistantLight, SphereLight, RectLight and DiskLight, sorted by path; dome the first DomeLight. A scene without lights renders black.
  • ground: the first visible GroundPlane.
