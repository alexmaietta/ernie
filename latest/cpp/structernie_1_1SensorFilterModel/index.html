Detailed Description

It has a nested Params struct of one float field per parameter, in order. The module imports sensor for the interfaces, SensorPixel, PixelContext and SpatialImage. A spatial filter splits the kernel: what comes before it writes its domain to an image, which it reads, heading a kernel of its own for what follows on its branch.
