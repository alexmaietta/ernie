Class ernie::MappedFile

ClassList > ernie > MappedFile

A file mapped read-only into memory: its bytes are read from disk as they are first touched, so a file far larger than memory can be read in parts, the operating system keeping what is used.

  • #include <ernie/util/mapped_file.h>
