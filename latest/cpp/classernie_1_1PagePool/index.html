Class ernie::PagePool

ClassList > ernie > PagePool

The software path of virtual textures, for devices without sparse residency and textures larger than the device's images: resident tiles live in pages, the layers of one 2D array image, which shaders find through a page table ( VirtualTexture ) and filter themselves (bilinear within a page, trilinear across two mips).More...

Detailed Description

A page is kPageTexels square: a kTileTexels tile with a border of kBorder texels from its neighbours (clamped at the texture's edges), so bilinear filtering near a tile's edge stays in its page. Every size is a whole number of 4 x 4 blocks, so BC tiles are cut from BC sources as they are. Mips of at most one tile form the tail, a plain image with mips.

Writes are copied in submissions the host does not wait for, ordered before work submitted after them.

Reference: J. M. P. van Waveren, "Software Virtual Textures", id Software, 2012.
