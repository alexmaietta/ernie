Detailed Description

Shapes and strides are in elements, as in DLPack; empty strides mean row-major contiguous. Copies share the memory and its owner. FromDlpack adopts a producer's tensor without copying and calls its deleter when the last Tensor referencing it is gone; ToDlpack hands memory to a consumer the same way.

Reference: DLPack, https://dmlc.github.io/dlpack/latest/
