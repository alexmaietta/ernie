Detailed Description

Bulk per-element data goes in a Tensor instead.

Strings serve both as USD tokens ("invisible", "lambert") and asset paths, and string lists as token arrays such as xformOpOrder; Path values are relationship targets such as material:binding, and path lists relationships with several targets such as a PointInstancer's prototypes. Quaternions are rotations such as xformOp:orient.
