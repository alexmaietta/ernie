Struct ernie::DomeParams

ClassList > ernie > DomeParams

An environment light at infinity (UsdLux DomeLight ) resolved for a frame (DomeParamsOf ): radiance from every direction, the spectrumradiance (W m^-2 sr^-1 nm^-1 per camera band) times a relative RGB map whose cosine-convolved spherical harmonics aresh .More...

  • #include <ernie/session/frame_params.h>

Detailed Description

It lights surfaces diffusely, with the BRDF's albedo, and is not occluded.

Reference: R. Ramamoorthi and P. Hanrahan, "An Efficient Representation for Irradiance Environment Maps", SIGGRAPH 2001, 497-500. https://doi.org/10.1145/383259.383317
