Class ernie::GradientNoise

ClassList > ernie > GradientNoise

Perlin's improved gradient noise in three dimensions, its lattice shuffled by a seed, for procedural fields such as volumes' density: smooth, zero at every integer point, and within about [-1, 1]. More...

  • #include <ernie/util/noise.h>

Detailed Description

The same seed gives the same noise everywhere, from C++ or Python (ernie.fbm_noise), so demo twins build the same fields.

References: * K. Perlin, "Improving Noise", ACM Transactions on Graphics 21(3) (SIGGRAPH 2002), 681-682. https://doi.org/10.1145/566654.566636 * F. K. Musgrave, "Fractal Solid Textures", in D. S. Ebert et al., Texturing and Modeling: A Procedural Approach, 3rd ed., Morgan Kaufmann, 2003 (fractional Brownian motion).
