Detailed Description

An image lives in a linear shared Vulkan image where the device samples those (VulkanContext::SupportsLinearSampling): a CUDA array view of it (Map) is the texture itself, written in place with no copy, and CUDA images logged from elsewhere arrive by one device-to-device copy. Host images are staged through the frame. Everything logged belongs to the registration scope current when first logged (Viewer::SetScope).

References: * Newton's viewers (newton.viewer: log_scalar, log_array, log_image), https://github.com/newton-physics/newton
