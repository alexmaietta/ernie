Detailed Description

Names are identifiers: a letter or underscore followed by letters, digits and underscores. A default-constructed path is empty and names nothing. Paths order by their text, so a prim's descendants follow it contiguously.

Reference: Pixar, "SdfPath", https://openusd.org/release/api/class_sdf_path.html
