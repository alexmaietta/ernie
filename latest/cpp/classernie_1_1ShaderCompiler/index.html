Detailed Description

Modules are loaded from source in the order given, so a module must come after the modules it imports. Compilation targets SPIR-V 1.6 for Vulkan; CompileWgsl emits the same program as WGSL, which keeps shaders usable by a future WebGPU backend.

Reference: Y. He, K. Fatahalian and T. Foley, "Slang: language mechanisms for extensible real-time shading systems", ACM Transactions on Graphics 37(4), 141, 2018. https://doi.org/10.1145/3197517.3201380

Compiled SPIR-V is kept on disk between runs, keyed by a hash of the Slang version, the target, the entry point and every module's name and source, so a program compiles once until its sources change: in ERNIE_SHADER_CACHE (empty or "0" keeps none), else the user's cache folder ($XDG_CACHE_HOME/ernie/shaders, ~/.cache/ernie/shaders).

Exception:

  • std::invalid_argument with Slang's diagnostics if a module fails to compile or the entry point is missing.
