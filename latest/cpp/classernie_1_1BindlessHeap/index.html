Class ernie::BindlessHeap

ClassList > ernie > BindlessHeap

Detailed Description

Buffers need none: shaders read them through their addresses (GpuBuffer::Address).

A slot's descriptor is written when it is added, while the set may be bound (update after bind), and a freed slot is reused only a few frames later (AdvanceFrame), or once the device is idle when the heap runs out, so work in flight never sees it change.

Reference: Khronos, VK_EXT_descriptor_indexing (core in Vulkan 1.2), https://docs.vulkan.org/features/latest/features/proposals/VK_EXT_descriptor_indexing.html
