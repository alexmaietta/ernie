Class ernie::app::FileDialog

ClassList > ernie > app > FileDialog

A modal file browser drawn with Dear ImGui, which Viewer shows forOpenFileDialog : a folder's contents with an Up button, an editable path and shortcuts to home, the working directory, the root and the folders used recently, a name field, a file type menu and Open (or Save) and Cancel.More...

Detailed Description

Double-clicking a folder enters it and a file chooses it.

Its state and choices (Navigate, Accept) work without ImGui, so applications and tests can drive it; Draw needs an ImGui frame.
