Namespace ernie::memory

Namespace List > ernie > memory

The device memory Ernie's buffers and images hold, for the viewer's Profiler panel: each live GpuBuffer andGpuImage registers its allocation under a category from its usage (render targets, textures, storage buffers, ...) until it is released.
