Detailed Description

Index space puts a value at each integer coordinate; the grid's map takes index coordinates to the grid's own frame (OpenVDB's "world", which a Volume prim's transform then places).

References: * K. Museth, "NanoVDB: A GPU-Friendly and Portable VDB Data Structure For Real-Time Rendering And Simulation", ACM SIGGRAPH 2021 Talks. https://doi.org/10.1145/3450623.3464653 * K. Museth, "VDB: High-Resolution Sparse Volumes with Dynamic Topology", ACM Transactions on Graphics 32(3), 27, 2013. https://doi.org/10.1145/2487228.2487235 * NanoVDB's file layout, nanovdb/io/IO.h and FileMetaData in nanovdb/NanoVDB.h, OpenVDB 13.0.0.
