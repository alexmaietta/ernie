Detailed Description

Step the scene's UsdRender products (one image each, or a batch of views, ViewPosesOf) and map their render vars to the CPU or CUDA: Applications that draw into their own windows or command buffers use the RenderDelegate and its VulkanContext directly (Delegate, Context), as the viewer does.
