namespace ernie
Planetary digital elevation models, as the PDS archives them, and the local heightfields Ernie's Terrain draws of them.

Classes

Type Name
struct Change
A prim's changes since a consumer last looked.
struct ChangeCursor
A consumer's position in a scene's history; see Scene::Changes .
class Column
One attribute of many prims as rows of one array, as a simulation keeps its bodies' poses: written whole from any array (CPU or CUDA, DLPack, no copy), or mapped and written in place on the device asked for, each write one change ( ColumnChange ) whatever the number of prims.
struct ColumnChange
One attribute of many prims written whole as rows of one tensor ( Scene::Write of aPrimSet again, orScene::Unmap of it) since a cursor, asScene::Changes reports it to a consumer that takes the rows whole.
class ColumnStorage
Storage a consumer of columns offers for them on a device it reads them on, such as a renderer's interop buffers: a column mapped there ( Column::Map ) is then written where the consumer reads it, copying nothing.
struct Rows
Rows a consumer offers, and whether they are storage it keeps (mapped again, the same rows) rather than a copy made there for now.
class Prim
Handle to a prim in a Scene : its path plus the scene, for chained edits.
class PrimSet
A fixed list of prims to write rows of one tensor to at once ( Scene::Write ), such as a simulation's bodies every step: the scene looks the prims up the first time and keeps them, looking them up again only after prims are removed or for another scene.
class Scene
A lightweight, USD-shaped scene for Ernie: a tree of typed prims named by Path , each holding attributes by USD name, plus change tracking for render delegates.
struct Bound
Attributes that are rows of a column ( columns_ ): which, its row, and the column's version its tensors last took (Refresh ), so a column written whole costs its prims nothing until read.
class Selection
The prims of a type that hold some attributes ( Scene::Select ), as a Fabric query finds the buckets of a type and attributes: found again only once prims of the type come, go, or author or clear an attribute, and kept in onePrimSet meanwhile, so the columns of its attributes stay theirs from step to step.
