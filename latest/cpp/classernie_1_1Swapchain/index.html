Detailed Description

The surface comes from the window system (e.g. glfwCreateWindowSurface) and is owned by the swapchain from then on. Presentation uses an 8-bit UNORM format when available, so colours are written to the screen unchanged, as in offscreen targets; with vsync it waits for the display (FIFO), otherwise it presents as fast as frames come, without tearing where the surface allows (mailbox, else immediate).
