Struct ernie::SigmoidSpectrum

ClassList > ernie > SigmoidSpectrum

A smooth reflectance spectrum in Jakob and Hanika's sigmoid-polynomial form: s(lambda) = 1/2 + x / (2 sqrt(1 + x^2)) with x = c0 t^2 + c1 t + c2 and t the wavelength mapped from 360-830 nm to 0-1. More...

Detailed Description

It lies in [0, 1] at every wavelength and is flat for c0 = c1 = 0.

Reference: W. Jakob and J. Hanika, "A Low-Dimensional Function Space for Efficient Spectral Upsampling", Computer Graphics Forum (Proc. Eurographics) 38(2):147-155, 2019. https://doi.org/10.1111/cgf.13626
