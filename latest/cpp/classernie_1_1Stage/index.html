Class ernie::Stage

Detailed Description

They are attributes of the scene's root prim /, which stays untyped: the root's schema is this one, so Scene::Set checks them, edits are tracked and undone as any other, and scene files keep them under "/". The view is not a prim type (PrimTypes): no prim is defined as one.

Fallbacks are what Ernie draws with: z up and metres, which USD's own fallbacks (y up, centimetres) are not, so a scene from USD states its units. Ernie records other units for interchange without converting them yet.

The time code is the animation's clock, which an application sets as ovstage's apply_usd_time does (SetTime, in seconds); a render delegate's sensor clock (RenderDelegate::Time), which its steps advance, is apart from it, so animation can hold or loop while sensors run on.

References: * Pixar, "UsdStage" (stage metadata), https://openusd.org/release/api/class_usd_stage.html * Pixar, "Encoding Stage UpAxis" and "Encoding Stage Linear Units", https://openusd.org/release/api/group___usd_geom_up_axis__group.html * NVIDIA, ovstage ovstage_population_apply_usd_time.
