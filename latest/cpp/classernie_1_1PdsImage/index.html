Class ernie::PdsImage

A PDS3 image read in place from its mapped file: NASA's Planetary Data System's elevation models and mosaics (LOLA's and MOLA's gridded heights among them), their label attached at the file's start or in a .lbl file beside it. More...

Detailed Description

One band of 8-, 16- or 32-bit integers (signed or not) or IEEE floats, in either byte order; SCALING_FACTOR and OFFSET to physical values; MISSING_CONSTANT as no data; and a simple cylindrical (equirectangular) map projection's grid.

References: * NASA PDS, "Planetary Data System Standards Reference" 3.8, 2009 (the label's syntax, chapter 12; IMAGE objects, appendix A.21; IMAGE_MAP_PROJECTION, appendix A.22). * LOLA team, "LRO LOLA Gridded Data Record" (LDEM_*.LBL).
