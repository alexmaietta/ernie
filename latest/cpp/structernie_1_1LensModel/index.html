Detailed Description

A perspective lens has radial and tangential distortion (Brown-Conrady, in OpenCV's convention), which maps undistorted normalised image coordinates (x, y) = (X/Z, Y/Z) to distorted ones: x' = x (1 + k1 r^2 + k2 r^4 + k3 r^6) + 2 p1 x y + p2 (r^2 + 2 x^2) y' = y (1 + k1 r^2 + k2 r^4 + k3 r^6) + p1 (r^2 + 2 y^2) + 2 p2 x y A fisheye lens maps them to theta_d / r (x, y), with theta = atan(r) (OpenCV's fisheye model).

The rasterizer draws a pinhole image and the sensor resamples it through the lens; a fisheye reaching past 60 degrees off axis is drawn on cube faces instead (wide_view.h), its field angle below kMaxFisheyeFieldAngle.

References: * D. C. Brown, "Decentering Distortion of Lenses", Photogrammetric Engineering 32(3):444-462, 1966. * J. Kannala and S. S. Brandt, "A Generic Camera Model and Calibration Method for Conventional, Wide-Angle, and Fish-Eye Lenses", IEEE TPAMI 28(8):1335-1340, 2006. https://doi.org/10.1109/TPAMI.2006.153 * OpenCV, "Camera Calibration and 3D Reconstruction", https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html, and "Fisheye camera model", https://docs.opencv.org/4.x/db/d58/group__calib3d__fisheye.html
