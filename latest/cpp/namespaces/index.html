Namespace List

Here is a list of all namespaces with brief descriptions:

  • namespace ernie Planetary digital elevation models, as the PDS archives them, and the local heightfields Ernie's Terrain draws of them.
    • namespace app Editing a camera's sensor chain (the Camera panel's Filter Chain): aRenderProduct 'sernie:filters and its SensorFilter prims, as ordinary scene edits.
      • namespace icons Lucide icon glyphs (lucide-static 1.52.0, private-use codepoints) as UTF-8 strings, for text drawn with the viewer's font, which has the icons merged in: ImGui::Button(icons::kSave) , orstd::string(icons::kCamera) + " Camera" as a label.
      • namespace menu
    • namespace detail What the view macros expand to.
    • namespace log What Ernie prints about itself on standard output, as Warp does ( wp.config.quiet ,wp.config.verbose ): a banner once it starts on a GPU, with its version, device and cache folders, and a line for each shader it compiles, more with verbosity (shaders and textures its caches answer) and nothing when quiet.
    • namespace memory The device memory Ernie's buffers and images hold, for the viewer's Profiler panel: each live GpuBuffer andGpuImage registers its allocation under a category from its usage (render targets, textures, storage buffers, ...) until it is released.
    • namespace profiler Summaries of the profiler's frames ( ernie/util/profiler.h ) as Omniverse Kit's profiler window shows them: each zone nested in the zone that encloses it, with its time averaged over the frames, its share of the frame, and exports as text, JSON and a Chrome trace.
    • namespace reflectance_table
    • namespace render_vars Render var names, after Omniverse's where it has the quantity.
    • namespace solar_table
    • namespace tokens Prim type and attribute names, following UsdGeom, UsdLux, UsdShade and UsdRender where those schemas have the concept, with Ernie's own underernie: .
  • namespace std
