Namespaces

Type Name
namespace ernie
Planetary digital elevation models, as the PDS archives them, and the local heightfields Ernie's Terrain draws of them.

Classes

Type Name
class CloudLayersField
Ernie's procedural cloud layers: up to four layers over a repeating weather map, carved from tileable noise at each sample on the GPU (three-geospatial's clouds, after Horizon Zero Dawn's), in the field's frame with z up; a Volume 's density, its material's density scaling it.
class DenseField
Ernie's field of a dense array of values, such as a grid solver's smoke or dust each step (Warp's arrays): sampled as a NanoVDB grid of every voxel, which a device array fills in place on the GPU.
class FieldAsset
A field read from a file (UsdVol's FieldAsset ).
class FieldBase
A field of values over space, which Volumes name; its transform places the field in its Volume (UsdVol'sFieldBase ).
class NanoVDBField
Ernie's field of NanoVDB grids written as an array instead of a file, such as a simulation's each step (Warp's Volume.array() ): one of its grids, read as anOpenVDBAsset 's.
class OpenVDBAsset
A grid of a VDB file.
class Volume
A participating medium: fields, each named by a relationship field:<name> to a field prim, shaded by the boundMaterial 's volume inputs (density, albedo, emission, temperature).
