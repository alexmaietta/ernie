Type Name
struct SensorFilterModel
A sensor filter written in Slang, run in the fused sensor kernel like the built-in ones: a struct typeName in moduleslang implementingIBandFilter (kindBand , domainSpectrum ),IPixelFilter (kindPixel , on one of the other domains), or for kindSpatial , which reads the pixels around its own,ISpatialBandFilter (domainSpectrum ) orISpatialPixelFilter (the other domains).
struct SensorFilterOutput
One output of a sensor filter.
struct SensorFilterParam
A custom filter's parameter: a float its prim sets as inputs:<name> , or withsize above 1 an array of floats (float name[size] in the filter'sParams , such as a curve; sensor.slang'scurveAt reads one), which the prim sets as a float array of any length, resampled linearly tosize (a single number fills it).
class SensorFilterRegistry
Custom sensor filters a renderer can run, by SensorFilterModel::id .
struct SensorFilterStep
One filter of a product's chain: a SensorFilter prim's ernie:filter:type , a built-in's name or a registered filter's id, with the floats of itsinputs:* attributes by name (without "inputs:").
