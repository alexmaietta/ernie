Struct ernie::OverlayBatch

ClassList > ernie > OverlayBatch

Many overlay items of one kind from arrays on the host or a GPU ( Overlay::Batch ), such as one per world of a batched simulation, or a physics engine's bodies, contacts and particles: the renderer reads the arrays as they are, without copies to the host, and draws each item from them on the GPU.More...

Detailed Description

Arrays have one row per item: float32 but worlds, heads, poseIndices and count (int32), and contiguous; on a GPU, all on the renderer's compute device, read again every frame. Optional ones are empty when absent, the style's value standing for them.
