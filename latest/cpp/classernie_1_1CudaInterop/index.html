Detailed Description

The CUDA driver (libcuda) is loaded at run time, so Ernie has no build dependency on the CUDA toolkit; without an NVIDIA driver Create reports CUDA unavailable. CUDA work runs in the device's primary context, the one CUDA frameworks use, on the legacy default stream, so it is ordered after work that frameworks hand over through DLPack. Signals to Vulkan all go on the legacy stream, after an event recorded on the stream the work ran on, so values arrive in order however many streams write.

Reference: NVIDIA, CUDA Driver API, "External Resource Interoperability", https://docs.nvidia.com/cuda/cuda-driver-api/group__CUDA__EXTRES__INTEROP.html
