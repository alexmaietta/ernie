Class ernie::GpuTimer

ClassList > ernie > GpuTimer

Times GPU zones ( ERNIE_GPU_ZONE ) for Ernie's profiler (ernie/util/profiler.h ) with timestamp queries: a zone writes one timestamp where it starts and one where it ends in its command buffer, andCollect hands finished zones to the profiler without waiting for the device, then frees their queries by host reset (Vulkan 1.2's hostQueryReset).More...

Detailed Description

Zones are dropped while the profiler is not recording, or when the queries in flight run out.

References: * Khronos, Vulkan 1.3 specification, section 18.5 "Timestamp Queries".
