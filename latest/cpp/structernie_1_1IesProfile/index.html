Detailed Description

Files give a half, quadrant or single plane of a symmetric luminaire, which Sample mirrors.

References: * IES LM-63-19, Approved Method: IES Standard File Format for the Electronic Transfer of Photometric Data and Related Information, Illuminating Engineering Society, 2019. * I. Ashdown, "Parsing the IESNA LM-63 Photometric Data File", 1998, http://lumen.iee.put.poznan.pl/kw/iesna.txt * G. Ward, Radiance ies2rad, source.cal and tilt.cal (type B coordinates and tilt angles), https://github.com/NREL/Radiance/tree/master/src/cv
