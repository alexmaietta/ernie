Class ernie::app::DemoRunner

ClassList > ernie > app > DemoRunner

Runs demos as Newton's examples run: opens the viewer the options ask for (or none), runs a demo until its window closes or it has run its frames, then writes --output , runs its final test and reports the benchmark.More...

Detailed Description

In a window, a Demos panel switches between the catalogue's demos in the same viewer, and pauses, steps and resets the running one.
