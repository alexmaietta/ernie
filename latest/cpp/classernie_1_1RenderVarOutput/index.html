Detailed Description

Outputs stay valid while any RenderVarOutput of the frame lives, and keep its image from being rendered over: drop them (after unmapping) so later steps can reuse the frame. They must not outlive the delegate that rendered them.

function Map

Maps the output to device .

MappedRenderVar ernie::RenderVarOutput::Map (
    MapDevice device,
    std::uintptr_t syncStream=1
)

GPU mappings make compute stream syncStream (DLPack numbering for the device kind; for CUDA 1 legacy default, 2 per-thread default) wait on the GPU for the render, without blocking the host; a CPU mapping waits on the host. Gpu and Cpu tensors own their texels; a GpuArray is the frame's image, which must be unmapped before the frame is dropped, and is not available for the layered SpectralRadiance or a batch of views.

Exception:

  • std::invalid_argument for a GPU device without compute interop, or a format compute arrays do not support.
