Detailed Description

Small values (Value: scalars, vectors, matrices, tokens, relationships) are set one at a time; bulk data (Tensor: heights, points, instance transforms) is written as tensors, either to one prim or as rows of one tensor spread over many prims without copying. On a prim of a registered type (prim_type.h), setting and writing check the attribute against its declaration (Validate): a misspelt name or a value of the wrong type throws, while custom attributes in namespaces of their own are free.

Every edit advances Version() and stamps the prim's dirty bit for that attribute (DirtyOf); transform and visibility edits stamp the prim's descendants too. Each consumer keeps a ChangeCursor and calls Changes to get every prim changed since its last call, so several consumers can follow one scene independently. Changes costs O(prims).

Defining a prim defines its missing ancestors as typeless prims, as UsdStage::DefinePrim does. The root / always exists, untyped.

References: * Pixar, "UsdStage", https://openusd.org/release/api/class_usd_stage.html * Pixar, "HdChangeTracker" (dirty bits), https://openusd.org/release/api/class_hd_change_tracker.html

function SetAt

Sets attribute 's value at time codetime , a time sample, as USD'sUsdAttribute::Set(value, time) does.

void ernie::Scene::SetAt (
    const Path & path,
    std::string_view attribute,
    double time,
    Value value
)

An attribute with samples holds, as its value (Get, Read), the one at the stage's time code (the root's ernie:timeCode), interpolated between the samples either side (Interpolate, time_samples.h) and held beyond the first and last; setting the time code evaluates every sampled attribute again, recording a change only where its value changed. Set or Write without a time clears the attribute's samples. Samples of an attribute are all values or all tensors: a sample of the other kind replaces them.

Exception:

  • std::invalid_argument if the prim does not exist or the value does not fit the attribute.

function Write [1/4]

void ernie::Scene::Write (
    const Path & path,
    std::string_view attribute,
    Tensor tensor,
    std::uintptr_t stream=1
)

The scene keeps the tensor, sharing its memory, until the attribute is replaced or removed. For a CUDA tensor, stream is the CUDA stream (DLPack numbering: 1 the legacy default stream, 2 per-thread default, else a CUstream) its contents are written on: consumers read it on the GPU in order after that stream's work queued so far.

Exception:

  • std::invalid_argument if the prim does not exist.
