Class ernie::app::Timeline

ClassList > ernie > app > Timeline

The animation's clock, as Omniverse Kit's timeline: plays the scene's time code ( Stage::GetTimeCode ) over the stage's range, from its start time code to its end, in real time or a frame at a time, looping or stopping at the end.More...

Detailed Description

It writes the time code into the scene's root, as an application sets it, outside the undo history; the renderer's sensor clock is apart from it.

Time codes run at the stage's time codes per second; a frame is the stage's frames per second's share of a second of them.

Reference: NVIDIA, Omniverse Kit omni.timeline (play, pause, stop, looping, play every frame).
