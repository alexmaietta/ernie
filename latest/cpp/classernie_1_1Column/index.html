Class ernie::Column

ClassList > ernie > Column

One attribute of many prims as rows of one array, as a simulation keeps its bodies' poses: written whole from any array (CPU or CUDA, DLPack, no copy), or mapped and written in place on the device asked for, each write one change ( ColumnChange ) whatever the number of prims.More...
