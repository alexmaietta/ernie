Detailed Description

Ernie's in-process profiler: the zones of ERNIE_ZONE and ERNIE_GPU_ZONE (ernie/util/profile.h, ernie/device/gpu_profile.h) recorded frame by frame for a profiler panel, alongside Tracy's (which streams them to its own viewer in a profiling build).

References: * NVIDIA, "Profiling", Omniverse Kit SDK manual (the Profiler window: GPU and CPU zone trees, depths, averaging, exports). https://docs.omniverse.nvidia.com/kit/docs/kit-manual/latest/guide/profiling.html * Google, "Trace Event Format" (complete events, "ph": "X", and thread-name metadata), read by Perfetto and chrome://tracing. https://docs.google.com/document/d/1CvAClvFfyA5R-PhYUmn5OOQtYMH4h6I0nSsKchNAySURecording is off until SetEnabled; while off a zone costs one atomic load.

A frame runs from one BeginFrame to the next: CPU zones belong to the frame in which they end, GPU zones to the frame in which their commands were recorded (they arrive later, once the device has run them). The latest frames are kept, oldest first (Frames).
